# Mnemosyne OS v6.2 Design: Cognitive Heat Engine + Distillation Enhancement

> 2026-08-05 | Design origin: archaeology of the "exploded legacy" (noah's dual-weight heat formula / soft-context prefrontal index table / SAB backup-tier rules)

## Background and problem

Measured (2026-08-05):
- `avg_heat_score = 0.10`, only 1 L1 hot memory (per stats)
- **Root cause**: heat only has "initial value 0.5 + pure multiplicative decay (0.98/4h)", with no "usage" signal at all — search hits don't update `access_count` and don't add heat
- The more a memory is used, the colder it gets; cross-session awareness of "what matters" goes numb

## Change list

### 1. Heat boost on search hit (main.py search_memories)
- Location: hybrid branch + created_at branch, before rows are returned
- Behavior: top 5 hits → `access_count+1, last_accessed=NOW(), heat_score=LEAST(1.0, heat+0.05)`
- Concept origin: the "access frequency" component of noah's dual-weight heat (0.4 weight)

### 2. Heat boost on recall hit (tmt/router.py tmt_recall)
- Location: after candidates are aggregated
- Behavior: top 3 final candidates (src=memories) get the same heat boost as above

### 3. Differentiated decay (tmt/router.py tmt_decay)
- Location: UPDATE on the memories table
- Behavior: `CASE WHEN last_accessed > NOW()-48h THEN heat*0.995 ELSE heat*0.98 END`
- Concept origin: the "time decay" component of heat — active memories decay 2.5x slower, staying hot

### 4. Heat signal on distillation ingest (tmt/distill.py)
- Distilled knowledge/pitfall entries are stored with heat=0.65 (default 0.5 → 0.65, an initial "new knowledge" signal)
- In-batch dedup: similar summaries within the same batch are cross-checked to avoid redundant distillation within a batch

### 5. Cross-check against backup rules (GZ backup.sh)
- noah's backup rules: tier S (memories/skills/config must be backed up) vs tier B (reinstallable, no backup needed)
- Check whether backup.sh covers: PG data + repo + .env + skills

## Validation plan
1. Create a memory → search hit → assert heat increases
2. Manual decay → assert decay difference between recently-accessed vs long-untouched
3. In-batch dedup in distill: two similar candidates → assert the second is skipped
4. Change in avg_heat / L1 hot-memory count
