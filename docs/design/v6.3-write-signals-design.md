# Mnemosyne OS v6.3 Design: Cognitive Write Signals

> Historical design doc — written as "Mnemosyne OS" (since renamed to Minnas). Content preserved as-is.

> 2026-08-05 | Design origin: noah gen-3's "drawer cascade compaction engine" temperature design (importance scoring table, hard-coded logic, no LLM dependency)

## Background

v6.2 already solved "search hits don't add heat" (heat now has a usage signal). But **the write side still has no cognitive signal**:
- Every memory is written with heat=0.5 (0.65 for distillation) — an "unfinished task" and "small talk" get the same initial heat
- Decay treats everything equally, so important knowledge gets diluted by time just like everything else

The drawer cascade's temperature design (battle-tested across noah gen-3):
```
Unfinished task +5 | User correction +4 | Decision record +3 | Emotional spike +3
Path/API change +2 | Tool result +1 | Small talk/ack 0
```

## Change list

### 1. Write-time importance signal (main.py create_memory)
- At write time, run pure regex signal detection on content (hard-coded logic, no LLM call):
  | Signal | Regex keywords (Chinese source text, kept as-is — matched against Chinese memory content) | heat bonus |
  |:-----|:----------|:---------:|
  | Unfinished task | 待办/下一步/TODO/pending/未完成 | +0.15 |
  | User correction | 不是/错了/不要/应该/修正/记住 | +0.10 |
  | Lesson learned / pitfall | 坑/教训/报错/失败/注意/踩过 | +0.10 |
  | Decision/plan | 决定/方案/采用/架构/设计 | +0.08 |
  | Path/API | 路径/端口/API/配置/key | +0.05 |
  | Marked important | 重要/关键/核心/必须 | +0.05 |
- Category bonus: preference/knowledge/pitfall → +0.10 (inherently important)
- Initial heat = clamp(0.5 + signal bonus + category bonus, 0.3, 0.8)

### 2. Protected decay for important memories (tmt/router.py tmt_decay)
- Pinned memories (metadata.pinned=true) or category=preference → decay ×0.995
- All others → ×0.995 if active within the last 48h, else ×0.98 (unchanged from v6.2)
- Effect: user preferences / important knowledge stay hot over the long term

### 3. Heat linkage on distillation ingest (tmt/distill.py)
- Distilled summary containing "坑/教训" (pitfall/lesson keywords) → heat 0.70 (pitfalls are inherently important)
- Everything else stays at 0.65

## Validation plan
1. Write "TODO: xxx" → heat ≥ 0.65; write small talk → heat ≈ 0.5
2. After decay: preference decays less than ordinary memories
3. Distilled pitfall is stored with heat=0.70
